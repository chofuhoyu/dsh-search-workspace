# dsh-search-workspace

给 DeepSeek Harness 的工作区列表加搜索：在**左侧栏**里按名称或路径找到任意工作区，并让**新会话的工作区选择**也能直接搜索。

工作区多了以后，左侧栏的会话搜索只能找到“某个会话”，找不到“某个工作区”。本插件补上后者，并且不改动、不替换左侧栏原有的工作区/会话列表。

## 安装

在 DeepSeek Harness 的「插件」页点击「添加插件」，填入：

```text
github:chofuhoyu/dsh-search-workspace
```

也可以直接用 CLI 安装到目标 profile：

```sh
dsh plugin --profile desktop add github:chofuhoyu/dsh-search-workspace
```

安装后刷新 Web 页面。

## 用法

### 1. 左侧栏：查找工作区

左侧栏底部、「设置」上方多出一行「查找工作区」：

- 点击它（或按 `Cmd/Ctrl + Shift + K`）打开查找对话框；
- 输入工作区名称、路径片段，或多个词（空格分隔）组合筛选；
- `↑` / `↓` 选择，`Enter` 打开，`Esc` 关闭；
- 打开行为：进入该工作区最近更新的会话；如果没有可用会话，就在该工作区新建一个；
- 对话框底部「在此新建会话」始终为高亮的那个工作区新建会话。

### 2. 新会话：工作区选择也能搜索

在新会话页面点击工作区胶囊（文件夹图标 + 当前工作区名）后，弹出的列表顶部多出搜索框：

- 输入即筛选，`↑` / `↓` 选择，`Enter` 确认，`Esc` 关闭；
- 直接点击仍然保持原来的选择行为；
- 名称重复的工作区会显示足以区分的路径后缀；
- 底部「添加工作区…」保留，仍会打开原生目录选择器，并把这个目录注册为工作区。

## 匹配规则

- 不区分大小写；
- 每个空格分隔的词都必须出现在名称或路径中；
- 名称开头命中优先，其次名称中段，最后路径命中；
- 名称重复时显示最短的区分路径后缀；标题是自动生成的 `default-workspace` 时显示当前语言的「默认工作区」。

## 设计说明

左侧栏的工作区/会话列表属于原生 `sidebar.workspaces` 单占位槽，并且它声明了自己的子槽（会话行操作、目录选择流等）。另一个插件如果整体遮蔽它，就必须同时接管这些子槽和目录选择器；因此 0.0.1 采用**增量**方案：

- `sidebar.footer.action` 增加入口，`shell.overlay` 承载查找对话框；左侧栏原有列表、拖拽、置顶、归档、右键菜单和会话搜索全部保持不变；
- `conversation.hero.workspace` 以 `priority: -1` 遮蔽原生工作区选择器，只替换这个下拉。原生注册仍然保留，其目录选择子槽也继续存在；本插件的「添加工作区…」通过原生 `uiWorkspace` 服务直接选择目录，因此不需要重新声明子槽。

界面组件（`Modal`、`Input`、`Button`、`Tooltip`、图标）直接复用 Harness 自带的
`@deepseek-ai/dsh-client-ui-primitives`，样式只使用 `--dsw-*` 主题 token，因此浅色/深色、
圆角、描边、阴影和弹窗行为都与原生界面一致。

## 配置

没有插件配置。快捷键可以在「设置 → 通用设置 → 快捷键」里改键；命令名是「查找工作区」
（`workspace.search`）。

## 限制

- 左侧栏的工作区列表本身没有变成可筛选列表；搜索通过独立对话框完成。真正做到“在列表内筛选”需要整体替换原生 `sidebar.workspaces` 实现及其子槽，0.0.1 不承担这个改动。
- 查找结果只覆盖已注册的工作区；不会搜索工作区里的会话内容（会话内容搜索仍由左侧栏原有的搜索负责）。
- 需要 Web/Desktop 客户端；Host 半是空实现。

## 验证

离线检查：

```sh
node scripts/check.mjs
```

它会在 Node `vm` 中按客户端模块加载器的形式执行 `client.js`，然后对假的 Client context 运行
`apply`，断言：

- 左侧栏入口、查找对话框、新会话选择器三个注册仍然生效，且新会话选择器以 `priority: -1` 遮蔽原生项；
- 快捷键命令在无弹窗、侧栏抽屉、本插件对话框下的解析结果；
- 搜索匹配、排序、路径后缀和默认工作区标题；
- 客户端包只依赖 React 与 Harness 自带的 UI 基础组件，且样式没有字面色值。

这项检查不替代在真实 Harness 里安装并查看界面。
